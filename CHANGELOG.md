# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added

- Production readiness improvements
- Error boundary components
- 404 and error pages
- robots.txt and sitemap
- Cookie consent banner
- Skip to content link for accessibility

### Changed

- Improved logging to avoid sensitive data exposure
- Enhanced accessibility with ARIA labels and form labels

### Security

- Added security headers in next.config.js
- Input validation with Zod

## [0.1.0] - 2026-02-17

### Added

- Initial release
- Color contrast checker with WCAG 2.1 and APCA support
- Website accessibility analyzer
- Image accessibility analyzer
- Keyboard navigation checker
- Semantic structure analyzer
- Form accessibility analyzer
- Color palette suggestions
- Export results to PDF/JSON/CSS
- Saved color palettes with localStorage persistence
